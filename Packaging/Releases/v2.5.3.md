# Depup Code v2.5.3

AI Agent kini bisa dipakai dengan model gratis atau lokal, dan provider lain dapat
ditambahkan secara manual.

## Yang baru

- **Preset provider** — OpenRouter (`openrouter/free`), Groq, GitHub Models, Mistral,
  Ollama dan LM Studio (lokal, tanpa API key), Gemini, OpenAI, dan Copilot.
- **Provider manual** — tambahkan provider OpenAI-compatible apa pun dengan nama, URL API,
  dan model; simpan, ubah, atau hapus kapan saja.
- **Muat daftar model** dan **Tes koneksi** di pengaturan AI, jadi ID model yang usang
  tidak perlu ditebak.
- API key tersimpan terpisah per provider.

## Perbaikan

- Model tanpa tool-calling tidak lagi membuat mode Ask/Plan gagal; aplikasi mengulang tanpa
  tools. Mode Agent memberi pesan yang jelas bila model tidak mendukung tools.

## Catatan

Kuota dan daftar model gratis ditentukan provider dan bisa berubah. Model gratis dapat
dicatat provider; jangan kirim kode rahasia. Model lokal tidak mengirim prompt ke internet.
