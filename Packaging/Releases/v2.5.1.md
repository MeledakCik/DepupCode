# Depup Code v2.5.1

Rilis ini membuat pemasangan jauh lebih sederhana: satu file setup untuk Windows
x64, onboarding pertama kali yang jelas, dan paket yang siap diuji untuk Microsoft Store.

## Yang baru

- **Setup satu file** — `DepupCode-Setup-v2.5.1-win-x64.exe` memasang aplikasi untuk
  akun Windows saat ini tanpa hak Administrator. Tidak perlu mengekstrak ratusan file.
- **Wizard pertama kali** — setelah kebijakan privasi dibaca dan disetujui, pengguna
  memilih folder workspace, tema, dan ukuran font editor. Folder bisa dilewati dan
  dibuka kapan saja dari Welcome screen.
- **Integrasi Windows** — shortcut Start Menu, opsi shortcut Desktop, protokol
  `depup://` untuk login Depup Cloud, menu **Open with Depup Code** pada folder,
  dan uninstaller yang bersih.
- **Kebijakan privasi lebih mudah dibaca** — teks kebijakan ditampilkan terformat
  dengan nomor versi; persetujuan dicatat per akun Windows.
- **Kesiapan Microsoft Store** — skrip `build-msix.ps1` dan manifest MSIX dengan
  logo Store otomatis, plus checklist audit di `Packaging/Store/STORE_SUBMISSION.md`.

## Perbaikan

- Preview dan terminal WebView2 tidak lagi gagal saat folder aplikasi read-only
  atau dipasang sebagai paket MSIX (cache dipindah ke `%LOCALAPPDATA%\DepupCode\WebView2`).
- Dialog folder tidak lagi muncul otomatis setiap aplikasi dibuka.
- Data build `DEBUG` dipisahkan ke `DepupCode-Development` agar tidak bercampur
  dengan instalasi rilis.
- Pemasangan ulang tidak menimpa pengaturan pengguna.

## Unduhan

| Berkas | Keterangan |
| --- | --- |
| `DepupCode-Setup-v2.5.1-win-x64.exe` | **Disarankan.** Setup satu file, per-user, tanpa Administrator. |
| `DepupCode-Setup-v2.5.1-win-x64.exe.sha256` | Checksum SHA-256 untuk verifikasi unduhan. |
| `DepupCode-v2.5.1-win-x64.zip` | Portable. Ekstrak seluruh isi ZIP sebelum menjalankan `DepupCode.exe`. |

Verifikasi unduhan di PowerShell:

```powershell
Get-FileHash .\DepupCode-Setup-v2.5.1-win-x64.exe -Algorithm SHA256
Get-Content .\DepupCode-Setup-v2.5.1-win-x64.exe.sha256
```

## Persyaratan

- Windows 10 versi 1809 atau lebih baru / Windows 11, x64.
- Microsoft Edge WebView2 Evergreen Runtime (biasanya sudah terpasang di Windows 10/11).
- .NET Desktop Runtime **tidak** diperlukan karena paket self-contained.
- Internet pada pemakaian pertama fitur PHP lokal untuk mengunduh runtime
  PHP 8.4.27 + Apache 2.4.66 (sekitar 44.81 MB, diverifikasi SHA-256).

## Catatan penting

- Build ini **belum ditandatangani secara digital**, sehingga Windows SmartScreen
  dapat menampilkan peringatan. Verifikasi checksum di atas sebelum menjalankan setup.
- Paket MSIX **tidak** disertakan dalam rilis ini karena masih memerlukan identitas
  dan sertifikat dari Partner Center.
- Sertifikasi Microsoft Store tidak dijamin; lihat
  [checklist Store](https://github.com/MeledakCik/DepupCode/blob/main/Packaging/Store/STORE_SUBMISSION.md).
