# Privacy Policy — Depup Code

Last updated: 2026-11-02

Depup Code is a desktop application. By default, your code and project files stay on your device.

## Data we collect
- Account and authentication tokens you choose to save (encrypted with Windows DPAPI on your device).
- Optional cloud sync data when you explicitly use Depup Cloud features.
- Anonymous crash/error diagnostics only if you submit them.

## Data we do not collect
- We do not read or upload your source code without an explicit action.
- We do not require telemetry for core editor features.

## Third-party services
- Open VSX, GitHub, Vercel, Cloudflare, Railway, and other providers you connect are governed by their own privacy policies.
- Runtime downloads (PHP/Apache) are fetched directly from their official sources.

## Contact
For privacy questions, contact the Depup team through the project repository.
