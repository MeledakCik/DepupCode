Kebijakan Privasi

Terakhir diperbarui: 2 November 2026

Kebijakan ini menjelaskan perilaku demo web Depup Code. Pengaturan server dan penyedia hosting situs yang menerbitkan halaman ini dapat memiliki praktik privasi tambahan.

Penyimpanan di browser

Demo menyimpan data workspace, pengaturan, dan antrean demo di browser menggunakan IndexedDB dan localStorage. Data tersebut berada di perangkat/profil browser Anda, tidak dienkripsi oleh demo, dan dapat dibaca oleh skrip yang berjalan pada origin yang sama. Penandaan nilai sebagai “sensitive” hanya menyamarkan tampilannya di antarmuka; itu bukan enkripsi.

Jangan masukkan token, kata sandi, data pribadi, atau rahasia produksi ke demo ini. Hapus data melalui kontrol reset di demo atau pengaturan penyimpanan situs di browser.

Koneksi jaringan

  • Saat mode online aktif, demo meminta katalog situs dari alamat /api/sites pada URL Depup Cloud yang dikonfigurasi. Permintaan ini dapat mengungkap alamat IP dan metadata permintaan kepada server tujuan.
  • Halaman memuat Tailwind CSS dari cdn.tailwindcss.com dan font dari Google Fonts. Penyedia tersebut menerima permintaan browser dan metadata jaringan sesuai kebijakan mereka.
  • Aksi sinkronisasi dan deployment pada antarmuka ini adalah simulasi; demo tidak mengunggah isi workspace, pengaturan, atau token provider.
  • Kode demo tidak menggunakan cookie atau analitik. Penyedia hosting halaman dapat mengumpulkan log server sesuai konfigurasi hostingnya.

Kontrol Anda

Anda dapat menggunakan mode offline, membatasi koneksi pihak ketiga melalui pengaturan browser/jaringan, dan menghapus data situs dari browser. Tautan pihak ketiga tunduk pada kebijakan privasi masing-masing penyedia.

Kontak

Untuk pertanyaan atau permintaan terkait privasi demo, gunakan issue di repositori Depup Code.
